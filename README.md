# Amazon Sales Dashboard - Tableau Project

## Project Overview

This project presents an interactive Amazon Sales Dashboard built using Tableau. The dashboard provides a comprehensive view of sales performance, shipping analysis, fulfillment insights, category performance, and geographic sales distribution.

The objective of this project is to transform raw sales data into actionable business insights through interactive visualizations and KPI monitoring. 

---     

## Key Features

### KPI Metrics 
- Total Quantity Sold
- Total Revenue Generated 
- Total Orders Processed

### Interactive Filters
- Category 
- Ship Country
- Ship State
- Status 
- Courier Status

### Visualizations
- Ship Service Analysis
- Sales Channel Analysis
- Fulfillment Analysis
- Monthly Sales Trend
- Category Performance Bubble Chart
- Order Status Pie Chart
- State-Wise Sales Map
- Category-Wise Courier Status Heatmap

---

## Business Insights

- Expedited shipping generates higher sales than standard shipping.
- Amazon Fulfillment contributes significantly more revenue than merchant fulfillment.
- Set and Kurta are among the top-performing product categories.
- Sales performance varies across different states, enabling regional analysis.
- Monthly sales trends help identify business growth patterns and seasonal demand.
